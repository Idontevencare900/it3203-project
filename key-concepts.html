Key Concepts

These six ideas explain most of what you need to know about browser cookies. Each one builds on the others, so reading them in order helps.

1. The Web Is Stateless

Web servers treat every request as brand new. By default, a server does not remember that you just visited another page on the same site. Cookies solve this problem by giving the server a way to recognize you.

2. Sessions

A session is a period of activity, such as staying logged in. The server usually gives you a random ID number, which your browser stores in a cookie. On each request the browser sends the ID back, and the server uses it to find your information.

3. Cookie Security

Cookies can hold sensitive things, such as a login session ID, so they need protection. The Secure setting keeps a cookie from being sent over unsecured connections, and HttpOnly stops scripts on the page from reading it.

4. Cross-Site Tracking

When an advertiser places cookies on many different websites, it can recognize you on each one and build a profile of your interests. This is one of the biggest privacy concerns about cookies.

5. Consent

Laws such as the GDPR require many websites to ask permission before using non-essential cookies. That is why cookie banners appear when you visit a site for the first time.

6. Managing Your Cookies

You are in control of the cookies stored in your browser. You can view them, delete them, and block certain types in your browser's privacy settings. Deleting cookies will log you out of most websites, so expect to sign in again.
